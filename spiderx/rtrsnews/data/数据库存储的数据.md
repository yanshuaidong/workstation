## reuters_news 表

用于存储从浏览器插件接收的路透社新闻数据。


| 字段名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| id | INTEGER | - | 主键，自增ID |
| published_time | DATETIME | - | 新闻发布日期（必填，唯一，用于去重） |
| title | TEXT | - | 新闻标题（必填） |
| url | TEXT | - | 新闻地址（必填，完整URL） |
| status | INTEGER | 0 | 状态：0-未处理，1-已处理 |
| created_at | DATETIME | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | CURRENT_TIMESTAMP | 更新时间 |
