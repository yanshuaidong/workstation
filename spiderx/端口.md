# 爬虫服务启停与端口

## HTTP 服务

本目录原有的 HTTP 助手服务均已停用。`geminihelper`（原端口 1124）和 `doubaohelper`（原端口 1127）的服务及浏览器扩展代码已移除。

## 批量启停

在 `spiderx` 目录执行 `./runall.sh` 启动、`./stopall.sh` 停止以下五个服务：

- `clsnewscraper`
- `eastfutuscraper`
- `futurestop10`
- `gthtposiscraper`
- `thsnewscraper`（同花顺期货热点新闻，每小时一次，写入 MySQL `futures.fut_news`，供期货项目 `/news` 读取；不开 HTTP 端口）

它们均使用 `start_scheduler.sh` / `stop_scheduler.sh`。批量脚本显示执行结果，并跳过不存在的目录或缺少脚本的服务。

`bbgnews`、`rtrsnews` 和 `chatgpthelper` 已停用，相关代码已移除，端口 1123、1125、1126 不再使用。
